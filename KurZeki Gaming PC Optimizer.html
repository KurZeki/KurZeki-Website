Windows warned you? That’s expected.

KurZeki is a new app from an independent developer and isn’t code-signed yet. Chrome, Google Drive and Windows SmartScreen warn about any .exe they haven’t seen many people download. You don’t have to take our word for it: follow the steps, then check the file yourself.

Download anyway

When you see “This file type might be dangerous”, click Download anyway. Every .exe file triggers this box.

Run it from SmartScreen

If “Windows protected your PC” appears, click More info, then Run anyway. The button only shows after More info.

Allow Administrator

Click Yes on the Windows prompt. KurZeki runs as Administrator so it can change system settings like the power plan. Use Restore settings in the app to go back.

Check it yourself

Only run files you trust. Here’s how to confirm yours is the real KurZeki Booster.

Match the file hash

Open PowerShell and run this, then compare the result with the hash below.

Get-FileHash "$env:USERPROFILE\Downloads\KurZeki Booster.exe"SHA256: E8CA015D1B980446686A5986ACE0C27592A490F6321F99C91E427EC440F8C854
